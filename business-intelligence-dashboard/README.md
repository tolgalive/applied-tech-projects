# Business Intelligence Dashboard — Shoe World

A Power BI business intelligence solution built for a retail case study ("Shoe World"): turning raw sales/inventory data into an interactive dashboard for decision-making.

## What's included

- `Shoe World Data Set.xlsx` — the source dataset used to build the model
- `Shoe World_Dynamic Dashboard.pbix` — the Power BI report/dashboard (open with Power BI Desktop)

## What the dashboard covers

- Data modelling and cleaning from the raw retail dataset
- Interactive visuals (sales trends, product/category breakdowns, filters/slicers)
- A dynamic dashboard designed to support business decisions at a glance

Built as part of a BTEC Level 5 HND Business Intelligence unit.
