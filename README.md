# Applied Tech Projects

A collection of hands-on technology projects covering AI, IoT, networking, data/business intelligence, programming, computer systems, and 3D/VR development — built across a BTEC Level 5 HND in Digital Technologies (Cyber Security) and a Bachelor's degree at Murdoch University.

## Code & technical projects

- **[ai-retail-faq-chatbot](./ai-retail-faq-chatbot)** — Python retail FAQ chatbot with a Tkinter GUI, JSON-based knowledge base, speech response, and chat logging. ([standalone repo](https://github.com/tolgalive/ai-retail-faq-chatbot))
- **[arduino-smart-lighting-system](./arduino-smart-lighting-system)** — Arduino IoT project combining a light sensor and IR object detection to control LEDs automatically.
- **[business-intelligence-dashboard](./business-intelligence-dashboard)** — Power BI dashboard built from a retail dataset (Shoe World case study).
- **[big-data-visualisation](./big-data-visualisation)** — Power BI + presentation project analysing a large retail dataset (Bright Star case study).
- **[networking-cisco-design](./networking-cisco-design)** — Networked system design and simulation in Cisco Packet Tracer.
- **[networking-in-the-cloud](./networking-in-the-cloud)** — Cloud-based networking solution designed and simulated in Cisco Packet Tracer.
- **[ict159-programming-c](./ict159-programming-c)** — Modular C programs: a coin-change calculator and a menu-driven currency/records management system.
- **[ict170-computer-systems-assembly](./ict170-computer-systems-assembly)** — x86 assembly programs covering conditionals, loops, arithmetic, and string handling.

## 3D & VR

- **[blender-echoes-of-time](./blender-echoes-of-time)** — a modelled, textured, and animated 3D scene built in Blender.
- **[vr-game-streetbitesvr](./vr-game-streetbitesvr)** — a VR game built in Unity with the XR Interaction Toolkit (group project).

## Reports & case studies

- **[reports](./reports)** — written reports and case studies, several with real technical evidence (cloud security, cryptography, CVE detection).

Each folder has its own README with more detail on what the project does and how it's built.
