# Cloud-Based Networking Solution

Design and implementation of a cloud-based networking solution, simulated in Cisco Packet Tracer.

## What's included

- `Cloud network1.pkt` — Cisco Packet Tracer file for the cloud networking simulation (open with Cisco Packet Tracer)

## What it covers

- Designing a network solution with cloud connectivity in mind
- Configuring devices and verifying the setup within Packet Tracer
- Applying cloud networking concepts to a practical simulated environment

Built as part of a BTEC Level 5 HND "Networking in the Cloud" unit.
