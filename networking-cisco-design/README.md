# Networked System Design (Cisco Packet Tracer)

Design and simulation of a networked system, covering addressing, device configuration, and connectivity, built and tested in Cisco Packet Tracer.

## What's included

- `Network1.pka` / `Network2.pka` — Cisco Packet Tracer simulation files (open with Cisco Packet Tracer)

## What it covers

- Network topology design (routers, switches, end devices)
- IP addressing and subnetting
- Device configuration and verifying end-to-end connectivity

Built as part of a BTEC Level 5 HND Networking unit ("Principles and Design of Networked Systems").
