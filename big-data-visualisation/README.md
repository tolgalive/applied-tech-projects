# Big Data & Visualisation — Bright Star Retail

A big data visualisation project for a retail case study ("Bright Star"), using Power BI to explore and present a large retail dataset.

## What's included

- `Unit 5 Tolga Kara Bright star retail.pbix` — the Power BI report (open with Power BI Desktop)
- `Bright star retail presentation Tolga kara.pptx` — presentation summarising the findings

## What it covers

- Handling and modelling a large retail dataset
- Building visualisations to surface trends and patterns (sales, performance, comparisons)
- Presenting data-driven insights in a business-friendly format

Built as part of a BTEC Level 5 HND Big Data & Visualisation unit.
