# Foundations of Programming (C)

Two C programming assignments covering algorithms, functions, arrays, and file handling.

## Projects

- **[assignment1-coin-change-calculator](./assignment1-coin-change-calculator)** — takes an amount and currency, then calculates the minimum coins/notes needed to make that amount.
- **[assignment2-currency-converter](./assignment2-currency-converter)** — a modular, menu-driven program that reads people's records from a file, computes coin change breakdowns for each, and lets the user search and display records (split across `main.c`, `menu.c`, `display.c`, `fileio.c`, `search.c`, `change.c`, `currency.c`, `records.h`).

Built as part of a Murdoch University unit, ICT159 Foundations of Programming.
