# StreetBitesVR (VR Game)

A VR game built in Unity with the XR Interaction Toolkit: a food-truck/kitchen-themed VR experience with 3D environment design, custom-modelled and textured assets (including a custom food truck built in Blender), and VR interaction setup (grabbing, hand tracking, XR rig).

**Group project** — built together with Minou Rousta (team "FrostArrow"), as part of the ICT288 course's group assignment. My contributions focused on 3D asset creation (Blender food truck model and environment props) and VR scene/interaction setup.

## What it covers

- Setting up a VR project with Unity's XR Interaction Toolkit
- Building and texturing custom 3D assets in Blender (food truck, kitchen props) and importing them into Unity
- Assembling an interactive VR environment (scenes, prefabs, lighting)
- Game design documentation (mechanics, narrative, target experience)
